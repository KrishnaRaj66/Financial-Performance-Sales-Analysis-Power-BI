# Financial Performance & Sales Analysis Dashboard | Power BI

## 📊 Project Overview

This project is an interactive financial and sales analysis dashboard developed using Microsoft Power BI.

The report analyzes sales, expenses, profit, revenue, year-over-year sales growth, and the relationship between marketing expenses, R&D expenses, and sales performance.

## 📌 Dashboard Highlights

- Total Sales KPI
- Total Expenses KPI
- Profit KPI
- Profit analysis
- Year-over-Year (YoY) Sales Growth
- Sales trend by year
- Relationship between Marketing Expenses, R&D Expenses, and Sales
- Financial summary by Year and Business Unit
- Interactive Year and business-related slicers
- Detailed report page for deeper analysis

## 🚀 Power BI Features Demonstrated

- DAX measures
- KPI cards
- Interactive slicers
- Time-based analysis
- Year-over-Year analysis
- Combo charts
- Line and column charts
- Pie/column visualizations
- Matrix/pivot-style analysis
- Report navigation and interactive filtering
- Data modeling
- Power Query / data transformation

## 🧮 Data Model

The report contains a `Financials` table and a dedicated `Measure Table` for analytical measures.

### Key Fields / Measures

- Sales
- Revenue
- Total Expenses
- Profit
- Year
- Business Unit
- Marketing Expenses
- R&D Expenses

## 🎯 Business Questions

This dashboard is designed to answer:

1. What are the total sales, expenses, and profit?
2. How is sales performance changing year over year?
3. Which years show stronger or weaker sales growth?
4. How do marketing and R&D expenses relate to sales?
5. How does financial performance vary by business unit?
6. What is the relationship between revenue, expenses, and profit?
